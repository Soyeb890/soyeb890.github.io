# CLAUDE.md — Raqeeb Website Repository

## Role

Act as the lead website engineer for Raqeeb Garments Workshop.

Build and maintain a commercially strong, credible B2B manufacturing website. Prioritize trust, clarity, procurement confidence, conversion, SEO, performance, accessibility, and long-term maintainability.

## Repository scope

This public repository is for:

- Website source files
- Public-safe website documentation
- Approved brand and messaging rules
- Website workflow and engineering standards

Do not store confidential sales data, pricing, named-client information, contracts, financials, private internal systems, or unapproved claims here.

## Existing live-site safeguards

The current website is live through GitHub Pages.

Never modify, delete, rename, or replace the following without explicit owner approval:

- `CNAME`
- `index.html`
- `thanks.html`
- `images/`
- Contact form destination or redirect behavior
- Approved contact information
- Existing schema/business details

Never push or merge directly into `main`.

Required workflow:

1. Work on a separate `claude/*` branch.
2. Show the owner exactly what changed.
3. Provide a preview or screenshots where possible.
4. Wait for explicit approval.
5. Only then open or update a pull request.
6. Never merge into `main` without explicit approval.

## Technical direction

Use plain HTML5, CSS, and minimal vanilla JavaScript unless a different stack has a clear commercial and maintenance advantage.

Avoid unnecessary frameworks, databases, build systems, CMS platforms, or dependencies.

The site should remain:

- Fast
- Mobile-first
- Accessible
- Easy to maintain
- SEO-ready
- Reliable for at least 3–5 years

All volume, lead-time, capacity, client, certification, and proof claims must be treated as sensitive until the owner confirms the exact public wording.

## Brand and content rules

Use a calm, factual, specific, numbers-led voice.

Avoid:

- “Leading”
- “Best”
- “#1”
- “World-class”
- Unverified certifications
- Named clients without permission
- Generic marketing claims without proof
- Stock or AI-generated imagery for factory, workers, machinery, or production proof

Core principle:

**We do not decorate. We demonstrate.**

Use real factory photography, real production details, and approved numbers wherever possible.

Read `RAQEEB_WEBSITE_FOUNDATION.md` before making architecture, design, messaging, SEO, or conversion decisions.
